SCS BUILD 548 - BALANCED MODE TEST REPORT

Architecture
- Balanced mode reuses Standard participation-first selection.
- Selected players are sorted by rating and frozen into Top/Bottom groups for the round.
- Rating values are not consulted again after the split.
- Balance is a hard candidate filter before Standard uniqueness/freshness scoring.

Rules
- Singles: Top vs Top or Bottom vs Bottom.
- Doubles: Top+Bottom vs Top+Bottom.
- Same-level doubles fallback: all four Top or all four Bottom, with equal team structure.
- XD additionally requires one man and one woman per team.
- MD/WD gender requirements are enforced.
- Exact previous-round game is penalized first among balanced candidates.
- Historical unique pairs/games remain preferred when balanced candidates exist.
