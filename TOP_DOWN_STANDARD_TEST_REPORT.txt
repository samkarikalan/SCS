SCS BUILD 546 — TOP-DOWN STANDARD ALGORITHM TEST REPORT

Implemented requirements
1. Equal total participation and interlinked rest fairness are selected first by DFS.
2. The app sends explicit required game counts derived from court inputs: MD, WD, XD, free doubles, men/women/free singles.
3. Typed and singles generators use the same fixed participation-first playing group in Standard mode.
4. Game-type history is sent separately from rest count. Actual rest count is never modified for type balancing.
5. Returning rested players and all-new/mostly-new/last-round-fresh court scoring remain active for free doubles Standard rounds.
6. Unique mode and Competitive mode routing are unchanged.
